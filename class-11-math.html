NCERT Chapter 12

Derivative of $\sin x$ by First Principle

★ High-Frequency 4-Mark Question
Statement: Prove from first principles of calculus that if $f(x) = \sin x$, then $f'(x) = \frac{d}{dx}(\sin x) = \cos x$.

Definition of First Principle:

$f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}$

Substitution:

For $f(x) = \sin x$, we have:

$f'(x) = \lim_{h \to 0} \frac{\sin(x + h) - \sin x}{h}$

Step-by-Step Proof Logic:

1. Apply $C-D$ identity: $\sin C - \sin D = 2 \cos\left(\frac{C + D}{2}\right) \sin\left(\frac{C - D}{2}\right)$.

2. $f'(x) = \lim_{h \to 0} \frac{2 \cos\left(x + \frac{h}{2}\right) \sin\left(\frac{h}{2}\right)}{h} = \lim_{h \to 0} \cos\left(x + \frac{h}{2}\right) \times \lim_{h \to 0} \frac{\sin(h/2)}{h/2}$.

3. Standard limit theorem gives $\lim_{\theta \to 0} \frac{\sin \theta}{\theta} = 1$ where $\theta = \frac{h}{2} \to 0$.

4. Thus, $f'(x) = \cos(x + 0) \times 1 = \cos x$. (Proved)

Direct Answer Key: $\frac{d}{dx}(\sin x) = \cos x$ Inspect Secant to Tangent Slope in 3D →
NCERT Chapter 3

Trigonometric Addition Identity: $\cos(x + y)$

★ Foundational Geometric Proof
Statement: Prove geometrically using the unit circle that $\cos(x + y) = \cos x \cos y - \sin x \sin y$.

Unit Circle Coordinates:

• $P_0 = (1, 0)$ on positive x-axis.

• $P_1 = (\cos x, \sin x)$ at angle $x$.

• $P_2 = (\cos(x + y), \sin(x + y))$ at angle $x + y$.

• $P_3 = (\cos(-y), \sin(-y)) = (\cos y, -\sin y)$ at angle $-y$.

Congruence & Distance Equivalence:

1. Triangles $\Delta P_0 O P_2$ and $\Delta P_3 O P_1$ are congruent ($\Delta P_0 O P_2 \cong \Delta P_3 O P_1$).

2. Therefore, chord lengths are equal: $(P_0 P_2)^2 = (P_1 P_3)^2$.

3. Expanding distances: $(\cos(x+y) - 1)^2 + \sin^2(x+y) = (\cos x - \cos y)^2 + (\sin x + \sin y)^2$.

4. Simplifying using $\cos^2 \theta + \sin^2 \theta = 1$ yields: $\cos(x + y) = \cos x \cos y - \sin x \sin y$. (Proved)

Direct Takeaway: Replace $y$ with $-y$ to instantly deduce $\cos(x - y) = \cos x \cos y + \sin x \sin y$. Rotate Angles in 3D Unit Circle →
NCERT Chapter 7

The Binomial Theorem for Positive Integers

5-Mark Pillar Theorem
Statement: For any positive integer $n$, prove by Mathematical Induction that:
$(a + b)^n = \binom{n}{0}a^n + \binom{n}{1}a^{n-1}b + \binom{n}{2}a^{n-2}b^2 + \dots + \binom{n}{n}b^n = \sum_{k=0}^n \binom{n}{k}a^{n-k}b^k$.

Induction Base & Hypothesis:

• For $n = 1$: $(a + b)^1 = \binom{1}{0}a^1 + \binom{1}{1}b^1 = a + b$. Base case holds.

• Assume true for $n = k$: $(a + b)^k = \sum_{r=0}^k \binom{k}{r} a^{k-r} b^r$.

Induction Step for $n = k + 1$:

1. Multiply by $(a + b)$: $(a + b)^{k+1} = (a + b) \sum_{r=0}^k \binom{k}{r} a^{k-r} b^r$.

2. Combine like terms with identical powers of $a$ and $b$.

3. Apply Pascal's Identity: $\binom{k}{r-1} + \binom{k}{r} = \binom{k+1}{r}$.

4. Result yields $\sum_{r=0}^{k+1}\binom{k+1}{r} a^{k+1-r} b^r$. Hence proved by PMI.

Direct Takeaway: Total terms in $(a + b)^n$ is $n + 1$; sum of all coefficients $\sum_{k=0}^n \binom{n}{k} = 2^n$. Test Binomial Coefficients in 3D →
NCERT Chapter 11

Distance Formula Between Two Points in 3D Space

Essential Spatial Foundation
Statement: Derive the Euclidean distance between points $P(x_1, y_1, z_1)$ and $Q(x_2, y_2, z_2)$ in three-dimensional Cartesian space.

Geometric Construction:

Construct a rectangular parallelopiped with $P$ and $Q$ at opposite corners.

Edge lengths parallel to axes: $|x_2 - x_1|$, $|y_2 - y_1|$, and $|z_2 - z_1|$.

Pythagorean Metric Steps:

1. Face diagonal in base plane: $d_{\text{base}}^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2$.

2. Space diagonal $PQ$ forms right triangle with base diagonal and height $|z_2 - z_1|$.

3. $(PQ)^2 = d_{\text{base}}^2 + (z_2 - z_1)^2$.

4. Thus, $PQ = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$. (Proved)

Alka Ma'am's Playbook

Alka Ma'am's 5 Golden Rules for 95%+ in Class 11 Math

✍️

1. Master the ASTC Quadrant System Completely

Trigonometry fails happen when signs are confused. Always sketch the 4 quadrants (All, Sin, Tan, Cos) and write the reference angle explicitly before computing values.

⚡

2. Treat Limits as Approaching Values, Not Direct Quotients

Never divide by zero directly. Factor polynomials or multiply by conjugates to cancel indeterminate forms $\frac{0}{0}$ before taking limits.

📐

3. Draw Accurate Conic Sketches with Directrices

In Parabolas, Ellipses, and Hyperbolas, a diagram identifying the focus coordinates $(c, 0)$ and directrix equation earns foundational presentation marks.

⏱️

4. Do Not Skip Mathematical Induction Proof Writing

Examiners look for the exact three sentences: Base Case $n=1$, Induction Hypothesis $n=k$, and Inductive Conclusion $n=k+1$.

🎯

5. Use 3D Simulators to Build Spatial Intuition

Geometry and calculus aren't flat formulas on paper. Use Alka Ma'am's virtual 3D labs to watch slopes, secants, and octants rotate before sitting for exams.

Class 11 CBSE Math FAQs

Frequently Asked Senior Secondary Questions

Direct answers to the most common questions asked by Class 11 students and parents.

Why is CBSE Class 11 Mathematics considered a major leap from Class 10?

Class 11 shifts from numerical calculation to abstract mathematical reasoning. Topics like formal Set Theory, Radian Measure, Trigonometric Transformations, and Calculus (Limits and Derivatives) establish the foundation for all engineering entrance exams (JEE) and Class 12 board scoring.

What is the difference between Core Math (041) and Applied Math (241)?

Core Mathematics (041) is theoretical and designed for Science and engineering streams focusing on trigonometry, 3D geometry, and pure calculus. Applied Mathematics (241) is built for Commerce, Economics, and Humanities streams, replacing trigonometry with financial math, taxation, descriptive statistics, and linear programming.

Which chapters carry the highest weightage in CBSE Class 11 Math?

Trigonometric Functions, Limits & Derivatives, Conic Sections, and Permutations & Combinations together account for more than 50% of the aggregate school examination weightage.
